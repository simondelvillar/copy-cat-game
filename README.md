# Copy Cat: The Matrix Exam

A lightweight browser game inspired by a cheating classmate. Peek at Alex's
paper, type the LaTeX answer, and hand it in. Alex is wrong about a third of
the time, so check the math. If the teacher catches you peeking or typing,
you lose a life.

## Features
- Matrix and arithmetic problems: add, subtract, scalar multiply, 2×2 product, determinant
- Custom LaTeX parser that accepts `pmatrix`, `bmatrix` and `vmatrix`
- Live matrix preview rendered with CSS grid, no libraries
- Teacher state machine with warning and watching phases
- Random photo jumpscare with sound, using your own images and audio
- Light and dark themes, mobile friendly, no build step
